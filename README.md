# Car_game# Toyota Racing 🏎️

A simple 2D racing game built with Python and Pygame.

## Features

- Player car movement
- Enemy cars
- Collision system
- Lives system
- Score system
- Best score
- Increasing difficulty
- Pause system
- Restart system
- Crash and game-over sounds
- Animated road markings
- Trees and road environment

## Controls

- ← → ↑ ↓ — move the car
- SPACE — start the game
- P — pause / continue
- R — restart after Game Over

## Requirements

- Python 3
- Pygame
